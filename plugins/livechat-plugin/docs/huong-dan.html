Hướng dẫn Chi tiết Sử dụng CMS LiveChat (Tài liệu Vận hành Official)

Dành cho Admin / CSKH / Moderation sử dụng Dashboard CMS để quản lý Domain (Site), Phòng chat (Room), Tin nhắn (Message), Người dùng (User), Moderation và Cấu hình hệ thống.

🔑 1.1 Truy cập Hệ thống
- URL đăng nhập CMS Admin: https://chatcms.us/#/login (hoặc URL do team vận hành cấp).
- Trình duyệt khuyến nghị: Chrome / Edge phiên bản mới nhất.
- Tài khoản: Do quản trị hệ thống cấp (phân quyền theo vai trò CSKH hoặc Admin).
💡 1.2 Các Khái niệm Chính trong Hệ thống
  • Site (Domain): Đại diện cho 1 website gắn widget chat. Mỗi site có cài đặt màu sắc, tin nhắn sticky và quảng cáo riêng.
  • Room: Phòng chat thuộc một site (Có thể là phòng chung, phòng theo trận đấu hoặc phòng hệ thống).
  • Message: Tin nhắn phát sinh trong room; hỗ trợ tìm kiếm, lọc nội dung và xóa phục vụ kiểm duyệt.
  • User: Người dùng chat (Tài khoản đã đăng ký hoặc khách ẩn danh); có thể chặn/mở chặn (moderation).
🌐 1.3 Quản lý Domain (Sites - URL: `https://chatcms.us/#/sites`)
Vào menu Danh sách Site để tạo mới hoặc điều chỉnh các tham số quan trọng:
Tham số / Trường Ý nghĩa nghiệp vụ Lưu ý vận hành
Domain Domain chạy widget chat (ví dụ: my-laravel-app.com). Nhập đúng định dạng URL, không chứa khoảng trắng thừa.
Sticky Message Tin nhắn ghim cố định ở đầu khung chat. Hỗ trợ HTML; chứa nội quy, hotline hoặc thông báo khuyến mãi.
Ẩn giao diện chat Tắt/ẩn toàn bộ Widget chat ở Frontend. Bật khi khẩn cấp cần hạ nhiệt hoặc bảo trì hệ thống.
Spam Config Giới hạn Max messages, Interval (s), Block duration (m). Đặt 2-5 tin nhắn trong 10 giây để chống rải bẩn link rác.
💬 1.4 Quản lý Phòng chat & Tin nhắn (URL: `https://chatcms.us/#/rooms`, `https://chatcms.us/#/messages`)
- Tạo & Lọc Phòng chat (Rooms): Lọc theo Domain, loại phòng (Trận đấu / Chung / Hệ thống). Tạo mới phòng chat gắn đúng Domain ID.
- Kiểm duyệt Tin nhắn (Messages): Lọc theo từ khóa, Room ID hoặc User ID. Thực hiện xóa 1 tin nhắn hoặc xóa hàng loạt các nội dung vi phạm pháp luật / rải link độc hại.
🛡️ 1.5 Kiểm duyệt Người dùng (User Moderation - URL: `https://chatcms.us/#/user-message`)
- Lọc danh sách user theo registered (Đã đăng ký) hoặc anonymous (Ẩn danh).
- Thực hiện Chặn (Block) / Mở chặn (Unblock) tài khoản vi phạm kèm nhập lý do chặn phục vụ đối soát CSKH khi có khiếu nại.
🤖 1.6 Phát tin Hệ thống (Bot Broadcast - URL: `https://chatcms.us/#/config`)
- Từ khóa cấm toàn hệ thống (Blocked Keywords): Khai báo danh sách từ khóa cấm phân cách bằng dấu phẩy.
- Phát tin tự động (Bot Broadcast): Nhập tên Bot hiển thị và nội dung để phát tin hàng loạt tới tất cả khách hàng đang chat trong các phòng.

Hướng dẫn Tích hợp Livechat vào ứng dụng Laravel

Tùy thuộc vào nhu cầu quản trị của ứng dụng Laravel, bạn có thể lựa chọn 1 trong 2 phương án tích hợp dưới đây:

⚡ 2.1. Tích hợp Livechat Widget Đơn thuần (Chỉ dùng Site ID)

💡
Mục đích: Dành cho các dự án Laravel chỉ cần hiển thị khung chat ở góc trang web cho khách hàng tương tác. Mọi cài đặt giao diện (màu sắc, banner) đều đã được chỉnh sẵn trên CMS Livechat và không cần trang cài đặt ở Backend Laravel.

Bước 2.1.1: Copy Assets vào Laravel

Copy thư mục livechat-plugin/assets/ sang public/livechat/ của dự án Laravel:

📁 public/livechat/ 
my-laravel-app/public/livechat/
├── AppCore-DWGzpKIy.js
├── livechat_plugin.js
└── livechat_plugin.css

Bước 2.1.2: Thêm Site ID vào `.env` và `config/services.php`

⚙️ .env 
LIVECHAT_ENABLED=true
LIVECHAT_SITE_ID=d0f9703e-9314-4506-96b6-a72d195b0664
📄 config/services.php 
<?php

return [
    'livechat' => [
        'enabled' => env('LIVECHAT_ENABLED', true),
        'site_id' => env('LIVECHAT_SITE_ID', ''),
    ],
];

Bước 2.1.3: Nhúng vào Blade Layout hoặc Component ``

📄 resources/views/components/livechat.blade.php 
@if(config('services.livechat.enabled') && config('services.livechat.site_id'))
    <!-- 1. CSS Livechat Widget -->
    <link rel="stylesheet" href="{{ asset('livechat/livechat_plugin.css') }}">

    <!-- 2. HTML Container mount Widget -->
    <div id="livechat_app"></div>

    <!-- 3. Biến toàn cục VITE_SITE_ID và Script Module -->
    <script>
        window.VITE_SITE_ID = @json(config('services.livechat.site_id'));
    </script>
    <script type="module" async defer src="{{ asset('livechat/livechat_plugin.js') }}"></script>
@endif

⚙️ 2.2. Tích hợp Livechat + Admin Setting Sync (Dùng Private Key & API)

⚡
Phân tích Mã nguồn Plugin (dv2-livechat.php): Hệ thống sử dụng Cơ chế Đồng bộ 1-Endpoint API (`POST /api/site/private/sync`) kết hợp thuật toán Chuẩn hóa MD5 Hash (`dv2_normalize_settings_for_hash`) để kiểm tra dữ liệu thay đổi và so sánh phiên bản (`wp_version` vs `serverVersion`).

Hướng dẫn Tích hợp Livechat vào WordPress (DV2 Livechat Plugin)

Nếu bạn đang phát triển hoặc quản trị một website chạy trên nền tảng **WordPress**, bạn có thể sử dụng trực tiếp Plugin **DV2 Livechat** (mã nguồn trong file dv2-livechat.php) để kết nối và quản trị Livechat ngay trong WP Admin.

📦 4.1 Cài đặt & Kích hoạt Plugin vào WordPress
1. Copy thư mục livechat-plugin vào thư mục wp-content/plugins/ của website WordPress (hoặc nén zip và upload qua giao diện WP Admin -> Plugins -> Add New).
2. Vào trang quản trị WordPress -> **Plugins** (Gói mở rộng) -> Tìm **DV2 Livechat** -> Bấm **Kích hoạt** (Activate).
🔑 4.2 Xác thực Kết nối (Site Token & Private Token)
Vào menu Live Chat Setting trên thanh điều hướng WP Admin (Screen 1):
  • Site Token (Site ID): Nhập mã Site ID từ CMS Livechat (ví dụ: d0f9703e-9314-4506-96b6-a72d195b0664).
  • Private Token (Private Key): Nhập mã Private Key dùng cho xác thực bảo mật.
  • Bấm nút Kết nối hệ thống. Plugin sẽ tự động gọi API GET /api/site/private để xác minh tính hợp lệ.
⚡ 4.3 Lựa chọn Phương thức Hiển thị Khung Chat
- Cách 1 (Tự động - Khuyên dùng): Tích chọn Tự động hiển thị ở Footer. Widget chat sẽ tự động được chèn vào góc dưới trang web thông qua hook wp_footer.
- Cách 2 (Thủ công qua Shortcode): Bỏ tích tự động hiển thị và chèn Shortcode [dv2_livechat] vào bất kỳ vị trí nào trên trang (Elementor, Gutenberg, Widget Sidebar...).
⚙️ 4.4 Quản trị Cài đặt Real-time ngay trong WP Admin
Sau khi kết nối thành công, màn hình Dashboard Vue 3 xuất hiện ngay trong Admin WordPress. Mọi thao tác lưu cài đặt sẽ tự động gọi API Sync 1-Endpoint đồng bộ dữ liệu giữa WordPress và Livechat Server mà không cần chỉnh sửa mã nguồn.

<!-- Nhúng Shortcode trong Gutenberg Editor hoặc Elementor Text Widget -->

Troubleshooting & Bảng FAQs

Vấn đề / Lỗi Nguyên nhân Cách xử lý
401 Unauthorized khi gọi API Sync Private Key trong `.env` bị sai hoặc không đúng định dạng Bearer Token. Vào trang CMS Detail Site kiểm tra lại LIVECHAT_PRIVATE_KEY và khai báo chính xác trong `.env`.
Widget không hiển thị ở Frontend Thiếu thẻ container #livechat_app hoặc `LIVECHAT_SITE_ID` bị trống. Đảm bảo đã khai báo <div id="livechat_app"></div> và gán đúng window.VITE_SITE_ID.
Uncaught SyntaxError: Cannot use import statement Thẻ <script> chưa có thuộc tính type="module". Sửa lại thẻ nhúng script: <script type="module" src="..."></script>.
Khung chat bị vỡ giao diện (Broken CSS) Xung đột CSS từ chủ đề Laravel hoặc thiếu file CSS của plugin. Kiểm tra xem file livechat_plugin.css đã nạp trong thẻ <head> chưa. Widget dùng Shadow DOM nên CSS cô lập tối đa.
