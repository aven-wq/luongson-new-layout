# Thapcam Layout Templates

Place your Thapcam layout template files here.

## Required Files

- `home-featured-streams.block.php`
- `hot-live-streams.block.php`
- `hot-blv-list.block.php`
- `stream-calander.block.php`
- `latest-highlights.block.php`
- `suggested-streams.block.php`
- `stream-detail.block.php`

## Usage

```
[dv2_home_featured_streams layout="thapcam"]
[dv2_hot_live_streams layout="thapcam"]
[dv2_hot_blv_list layout="thapcam"]
[lich_truc_tiep layout="thapcam"]
[highlights_moi_nhat layout="thapcam"]
[de_xuat_video layout="thapcam"]
[stream_detail layout="thapcam"]
```

If a template file doesn't exist, it will automatically fallback to the socolive layout.
