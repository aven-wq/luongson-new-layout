# Vebo Layout Templates

Place your Vebo layout template files here.

## Required Files

- `home-featured-streams.block.php`
- `hot-live-streams.block.php`
- `hot-blv-list.block.php`
- `stream-calander.block.php`
- `latest-highlights.block.php`
- `suggested-streams.block.php`
- `stream-detail.block.php`

## Usage

```
[dv2_home_featured_streams layout="vebo"]
[dv2_hot_live_streams layout="vebo"]
[dv2_hot_blv_list layout="vebo"]
[lich_truc_tiep layout="vebo"]
[highlights_moi_nhat layout="vebo"]
[de_xuat_video layout="vebo"]
[stream_detail layout="vebo"]
```

If a template file doesn't exist, it will automatically fallback to the socolive layout.
