# LuongSon Sport

Shortcodes:

- `[luongson_top_commentators]` — Top bình luận viên ticker
- `[luongson_home_match]` — Featured home match (stadium, ads ticker, teams, odds, CTA)
- `[luongson_list_matches]` — Live matches grid (“Đang phát sóng”: cards, mid-row ads, BLV dropdown, status modal)

Assets (CSS / JS / images) are bundled in the plugin so the UI works on any theme/page.
